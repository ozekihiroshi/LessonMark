# LessonMark documentation

- `PRODUCT_REQUIREMENTS.md`: v0.1 product scope and acceptance criteria
- `TECHNICAL_DECISIONS.md`: architecture decisions and milestones
- `AUTHORING_GUIDE.md`: supported Markdown and teaching syntax
- `INSTALLATION.md`: install, upgrade, and uninstall operations
- `RELEASE_CHECKLIST.md`: release gates and evidence requirements
- `M1_IMPLEMENTATION.md` through `M7_IMPLEMENTATION.md`: milestone records

Product scope changes belong in the product requirements. Implementation
choices that do not change product scope belong in the technical decisions
document. Release evidence belongs in the relevant milestone record and must
refer to the exact tested commit and artifact.
