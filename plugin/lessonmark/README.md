# LessonMark for Moodle

LessonMark is a Moodle activity module for creating and publishing teaching material whose source of truth remains Markdown.

Install this directory at `<moodle-root>/mod/lessonmark`.

M1 provides activity-module installation and CRUD, Markdown source storage, a shared Moodle-core renderer, raw HTML neutralisation, student display, capabilities, privacy metadata, view completion, a viewed event, and PHPUnit coverage.

The split Markdown editor and live preview are planned for M2.

## Requirements

- Moodle 5.2
- PHP 8.3 or 8.4
